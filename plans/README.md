# plans/

Specs, implementation plans, research notes, and working context for
this repo. One file per small effort, or a subfolder per larger effort
(e.g. spec.md + handoff.md + research/). Other subfolders (probes/,
scripts/, tests/, etc.) are fine — add them as the repo needs.

- Active work lives here at the root.
- `completed/` — finished work, moved here whole once shipped.
- Never commit secrets, tokens, or customer data in these docs.
